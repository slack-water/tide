Privacy policy

This policy covers personal integrations built on top of tide, such as a script that pulls sleep and activity data from the Google Health API into a private, single-user journal.

These integrations are personal tools used by a single individual (the developer). Data fetched via Google APIs is:

  • used only to populate the developer's own private log files;
  • stored only on the developer's own devices and in a private git repository the developer controls;
  • never shared with, sold to, or processed by any third party;
  • never used for advertising or analytics.

OAuth credentials and tokens are stored locally in the developer's system keychain, never committed to source control.
